# AutoRace - Construction Site and Overtaking Module
# Installation and Launch Instructions

## Prerequisites
- ROS2 Humble or Jazzy installed
- Python 3.8+
- OpenCV and cv_bridge installed

## Installation Steps

1. Clone the repository (if not already done):
   cd ~/ros2_ws/src
   git clone https://github.com/tywin812/AutoRace.git
   cd AutoRace

2. Checkout the feature branch:
   git checkout feat/construction-site-and-overtaking

3. Return to workspace root and build:
   cd ~/ros2_ws
   colcon build --packages-select lane_detection construction_and_overtaking
   source install/setup.bash

4. Launch all nodes:
   ros2 launch construction_and_overtaking obstacle_avoidance.launch.py

## Alternative: Launch Nodes Individually

If you need to debug or run nodes separately:

# Terminal 1 - Bird view calibration
ros2 run lane_detection bird_view

# Terminal 2 - Lane detection
ros2 run lane_detection detect_lanes

# Terminal 3 - Lane following control
ros2 run lane_detection follow_lanes

# Terminal 4 - Obstacle avoidance
ros2 run construction_and_overtaking obstacle_avoidance

## Viewing Topics

# Check lane distances
ros2 topic echo /lane_left_distance
ros2 topic echo /lane_right_distance

# Check LiDAR data
ros2 topic echo /scan

# Check lane detection state
ros2 topic echo /lane_detection_state

# Check avoidance status
ros2 topic echo /avoid_active

## Calibration Tips

1. First run lane_detection calibration mode to adjust HSV thresholds
2. Adjust obstacle detection thresholds in obstacle_avoidance.py:
   - obstacle_threshold (default: 1.0m)
   - lane_margin (default: 100 pixels)
   - avoidance_speed (default: 0.15 m/s)

3. Check LiDAR sector indices for your specific sensor configuration

## Troubleshooting

- If nodes don't start: Check that all dependencies are installed
- If camera not detected: Verify /color/image topic is publishing
- If LiDAR not working: Verify /scan topic is publishing
- If robot doesn't avoid: Check threshold values and LiDAR data

## Project Structure

lane_detection/
  ├── bird_view_calibration.py  # Camera perspective transformation
  ├── detect_lanes.py          # Lane detection + distance publishing
  └── follow_lanes.py          # Lane following control

construction_and_overtaking/
  └── obstacle_avoidance.py    # LiDAR-based obstacle avoidance
